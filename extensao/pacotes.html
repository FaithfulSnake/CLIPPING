Onde salvar os pacotes

não salvo

O Chrome está configurado para perguntar onde salvar cada arquivo, então na pasta Downloads a pasta do pacote não é criada sozinha. Escolha uma pasta para os pacotes (opção acima) ou desligue “Perguntar onde salvar cada arquivo” nas configurações de download do Chrome.

Cada pacote é uma pasta com o nome dele, com os ZIPs numerados na ordem das matérias (01 - …, 02 - …) e um arquivo Índice do pacote.txt que lista o que tem dentro. Antes de iniciar uma captura, escolha o pacote no popup da extensão: o ZIP vai direto para a pasta dele. Exportar pacote junta tudo num ZIP só, com a pasta do pacote e uma pasta para cada matéria.
